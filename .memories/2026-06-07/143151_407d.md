## Fixed Julie plugin stale extracted binary detection

- **WHAT:** Added an archive-basename extraction marker to the plugin launcher so a new `julie-vX.Y.Z-*` archive forces re-extraction even when an older extracted `julie-server` has a newer file timestamp.
- **WHY:** The pulled v7.13.3 rollout could show dashboard version 7.13.2 because the plugin launcher reused a cached extracted binary instead of extracting the newly installed archive.
- **HOW:** `prepareBinaryForLaunch()` now compares `.extracted-archive` with the current archive basename and writes the marker after successful extraction. `extractBinary()` returns whether extraction actually happened so Windows binary-lock fallback does not claim a fresh marker.
- **IMPACT:** Future plugin updates should not require manually removing the Claude Code plugin cache to clear an old Julie binary.
